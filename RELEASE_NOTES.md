CardMirror Green 1.16.17 — A Flow tab for each position

In an LD or Policy Flow, click Import tags. The import now recognizes styled position headings such as AD1, Advantage 2, Politics DA, Off1, CP and K. Each position gets its own named tab, with its tags in the speech column you choose. The dialog previews the tabs before you create them.

Keep One tab per position heading checked, then click Create sheets. Uncheck it to import the whole document into one filename-named tab. Tags before the first position, or in documents without recognized position headings, use a filename-named tab. Subheadings such as Link and Impact stay in their position. This is still a manual, one-time editable copy; one Undo removes all imported tabs, and Prep/Round restrictions remain in force.

On Windows or an Apple Silicon Mac, use Help > Check for Updates, save your work, then Restart to install.
