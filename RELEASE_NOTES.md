CardMirror Green 1.16.19 — Clearer Flow appearance and selection

Flow Appearance now keeps all six background options in a wrapping grid and shows the full highlight shortcut in a proper text field. Controls, labels and speech headers use the app's UI font while cells retain the font you choose. Shortcut capture no longer traps Tab or replaces the saved binding when a modifier or reserved key is pressed.

Six new muted colorways complement Soft and Soft dark: Sage & Plum, Slate & Rose, Periwinkle & Apricot, Seafoam & Lilac, Denim & Copper, and Olive & Mauve. Selected cells use a neutral background, and native text selection has contrasting text/background colors. Bright Soft-light hues are deepened for legibility; built-in Soft palettes pass selected-text contrast checks. Color-picker swatches now match HSL-derived palette colors.

On Windows or an Apple Silicon Mac, use Help > Check for Updates, save your work, then Restart to install.
