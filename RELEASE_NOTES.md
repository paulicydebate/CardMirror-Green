CardMirror Green 1.16.18 — Soft Flow themes

Flow Appearance now offers Soft and Soft dark: lighter typography, softened text colors, pastel speech colors and subtle background tints. Merriweather Sans is bundled with the app, so the new font works offline; bold cells retain their heavier weight.

Choose Soft or Soft dark in Flow > Appearance. Existing styles, custom side colors, document contents, collaboration and Prep/Round behavior are preserved. This release includes all earlier Flow drag-selection and position-tab import improvements.

On Windows or an Apple Silicon Mac, use Help > Check for Updates, save your work, then Restart to install.
